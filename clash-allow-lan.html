2026 苹果手机免 Shadowrocket 共享翻墙与免翻替代全攻略（Windows/Mac双平台保姆级教程）

很多刚使用苹果手机（iPhone）的小白用户会发现，国内 App Store 没办法直接下载 Shadowrocket（俗称小火箭）。这就产生了一个很尴尬的死循环：手机想要翻墙需要下载小火箭，但是想要下载小火箭又必须先翻墙。其实，只要你手头有一台已经能够正常翻墙的 Windows 电脑或 Mac 电脑（翻墙机场和教程），或者学会用免费的替代软件，就能轻松打破这个僵局。本文就用大白话手把手教你两种最简单的解决方法。

一、阶段一：利用电脑 Clash 共享网络（最快速、手机不用装任何软件）

服务特点： 只要 iPhone 和电脑连着同一个 Wi-Fi，就能把电脑当成网络中转站，让手机借用电脑的节点直接上网。

方案成本： 0 元（完全免费）。

客户端支持： 全平台电脑通用（以 Windows 端最新的 Clash Verge v2.5.2 为例）。

⚠ 注意：这个方法需要电脑一直开机、不能休眠，而且手机和电脑必须连着同一个 Wi-Fi。

🛠 核心配置实操流程

  • 第一步：电脑端 Clash Verge 核心设置 打开电脑上正在运行的 Clash Verge 客户端。
    1. 点击左侧导航栏的 “设置” (Settings)。
    2. 在通用设置中，找到 “局域网连接” 开关，将右侧开关打开（变成蓝色或绿色）。
    3. 此时无需到处寻找，新版软件默认的 端口号 (Port) 通常为 7897。
  • 第二步：一键获取电脑的“局域网 IP 地址” 在新版 Clash Verge 中，获取 IP 非常简单，完全不需要打开电脑的黑窗口命令行：
    1. 直接点击 “局域网连接”右侧的小图标（通常是个小电脑或分享图标），软件会自动弹窗显示你当前电脑的所有局域网 IP 地址。
    2. 找到形如 192.168.X.X 或 10.0.X.X 的地址并记录下来（例如：192.168.1.125）。

    • 💡 电脑端操作对照图（包含局域网开启、IP查看、端口确认）

  • 第三步：【关键步骤】让 Windows 防火墙允许手机连接 Windows 防火墙默认会挡住手机的连接，这一步必须做，否则手机连上后会彻底断网：
    1. 在电脑左下角搜索框输入 “高级安全 Windows 防火墙” 并打开。
    2. 点击左边栏的 “入站规则”，再点击右边栏的 “新建规则...”。
    3. 选择 “端口” -> 点击下一步。
    4. 选择 TCP，在下面填入刚才 Clash 的端口号（例如 7897） -> 点击下一步。
    5. 选择 “允许连接” -> 后面一路点击下一步 -> 最后随便取个名字（比如 Clash共享）保存即可。
  • 第四步：iPhone 手机端设置 拿起 iPhone，打开“设置” -> 进入“无线局域网 (Wi-Fi)”。
    1. 确保跟电脑连的是同一个 Wi-Fi，点击 Wi-Fi 名字右边的 “i”蓝色圆圈图标。
    2. 划到最下面，点击 “配置代理” -> 选中 “手动”。
    3. 依次填入刚刚查到的信息：
        - 服务器： 输入第二步查到的电脑 IP 地址（如： 192.168.1.125）。
        - 端口： 输入第一步记下的端口号（如： 7897）。
        - 认证： 保持关闭，不用动。
    4. 点击右上角的 “存储”。现在打开手机浏览器，就可以正常上网了。

💡 日常使用避坑提示：
1. 出门直接用，不用管：带手机出门用 4G/5G 移动网络时，不需要去改任何设置，手机能正常上国内的网络。
2. 电脑关机或不用时要关闭：如果你在家把电脑关了、或者把电脑上的 Clash 退出了，只要手机还连着家里的 Wi-Fi，就会因为找不到电脑而彻底断网（国内网站也打不开）。这时候必须回到手机 Wi-Fi 设置里，把“配置代理”改回“关闭”，手机才能恢复上网。

二、阶段二：利用自备美区 Apple ID 下载手机端软件（独立上网、随时随地用）

服务特点： 既然我们已经通过“阶段一”让手机临时连上了外网，就可以趁热打铁，在 iPhone 上下载能够独立运行的手机端客户端。配置完成后，手机就能完全脱离电脑，出门使用 4G/5G 移动网络也能随时随地顺畅上网。

前置准备： 进行本阶段操作前，需要您自己提前准备好一个美区 Apple ID。由于网络上公开的免费共享账号极不稳定、经常密码错误，甚至存在锁机风险，为了您的隐私和手机安全，强烈不推荐使用任何公共共享账号。

🛠 实操执行全攻略

  • 1. 安全登录自备的美区 Apple ID 因为国内应用商店屏蔽了所有网络加速工具，我们必须切换到美区商店。打开 iPhone 自带的 App Store（应用商店），点击右上角个人头像，拉到最底部点击 “登出” (Sign Out)。然后，在原地登录你自己的美区 Apple ID。

    ⚠ 新手安全避坑提示：千万不要在 iPhone 系统的全局“设置”里登录别人的账号，一定要在 App Store 这个单独的软件内登录！这可以 100% 防止因为网络或账号异常导致你的整台手机被远程锁死。

  • 2. 搜索并下载对应的软件（注意付费门槛） 登录成功且 App Store 界面自动刷新切换为美区后，在搜索框中输入你决定使用的软件名称：
    • 如果选择免费软件（如 Sing-box）：直接点击下载安装即可，不会弹出任何付费提示。
    • 如果选择付费软件（如 Stash / 小火箭）：由于国内的微信、支付宝和银联卡无法直接在美区商店付款，你需要先去正规平台购买「美区 Apple Gift Card（礼品卡）」充值到你的美区账号内，余额足够后才能点击下载。
  • 3. 导入配置与过河拆桥（关闭阶段一代理） 下载完成后打开软件。去你购买网络加速服务的网站，复制你的 Clash 订阅链接，粘贴到 App 里的配置栏中（通常叫 Profiles 或 Config）同步节点列表。
    最关键的一步来了： 当手机成功同步出节点并测试可用后，请立刻回到 iPhone 的“设置” -> “无线局域网 (Wi-Fi)”，把你在阶段一设置的“配置代理”重新改回“关闭”！
